# Onboarding and first run

**Core tasks:** reach the first useful result fast · understand what the product does by using it.

**Must exist**
- Empty states that explain *why* empty and offer the one next action; sample data option.
- Progress through setup that can be skipped and resumed.
- Defaults that work; no forced tour.

**Slop risks:** 3-slide carousel with illustrations; "Welcome to X! 🎉"; confetti.

**Astryx:** `ai-chat-landing` (composer + suggestion chips zero state), `library` (card grid with a real empty state), `login`, `login-card`, `login-split`, `login-sso`.
